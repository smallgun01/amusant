## Configuration boundary

The generic application configuration defaults an omitted or empty `AMUSANT_SLOW_EXECUTOR` to `hermes_runs`; the OCI Relay entrypoint also uses Hermes when the variable is absent while loading secrets. The Grok Compose profile explicitly selects `grok_callback`. Specify the intended executor in deployment configuration rather than inferring the effective profile from the product's Grok-first description. Changing the generic default requires a separate compatibility review across entrypoints and tests.

`AMUSANT_TASK_STORE` defaults to SQLite in the generic configuration; selection of a store is separate from executor selection. A configured selection is not evidence that every executor/store combination has been accepted or deployed. Do not reinterpret existing task rows or resend a Routine whose submission outcome is uncertain during a profile change.

The root [project definition](../../pyproject.toml) is the main dependency source. The OCI image uses Python 3.13 and the hardware Opus extra; the root historical AWS Dockerfile uses Python 3.12 with the DynamoDB extra. The `relay/` mock project is a distinct historical smoke-test definition. Resolve support and migration requirements before removing or consolidating any of these entrypoints.
