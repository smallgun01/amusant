# Phase 2A evidence

The committed artifact phase2a-gates-sanitized.json summarizes the final local run only. It contains gate outcomes and bounded evidence, but no Hermes Run IDs, prompts, provider request bodies, credentials, host paths, AWS identifiers, or private endpoints.

Attempt-level JSON files generated by run_poc.py are local-only and ignored by Git because they contain ephemeral test Run IDs. Earlier harness-only setup/configuration failures are retained locally for audit but are not counted as Hermes API gate results.

The final run used the fixed Kai-pinned Hermes image, a named local Docker volume, an internal-only network, no published ports, and a deterministic fake provider. The configured 65,536 context is a startup compatibility setting for the fake provider only, not a real model capability. Fargate/EFS, 30-day retention, cancellation, SSE replay, cross-owner isolation, and production tool isolation were not tested.
